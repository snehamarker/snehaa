# Sneha — Digital Playground

A bold, responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in your browser.

## Publish with GitHub Pages

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Customise

- Update the project descriptions and repository links in `index.html` as your work evolves.
- Add your preferred contact method in the contact section when you are ready to share it.
- The site uses Google Fonts; system fallbacks are included.
